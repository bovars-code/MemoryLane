# MemoryLane
MemoryLane is a 3D Unreal Engine 5 game centered around a forgetful cook, who through stories told by townsfolk remembers recipes.
<br>
## Synopsis and Motivations
This game is my capstone project for a game design course I'm taking part in. My group and I wanted to create a cozy, story-driven game, while also keeping some skill checks to keep the game engaging without including story elements. We implemented a simple cooking gameplay loop via blueprint scripting, low-poly visuals, and an NPC ordering system. 

While scripting the minigames for this project, we remembered how many of us used to play "Cooking Mama" as kids, which was our main inspiration for the said minigames. We also talked about spending hours playing Animal Crossing, which led us to take inspiration from the pixelated, simple, and cute art style of the game. 

Our main motivation was to create something non-stressful and fun. Through intuitive gameplay mechanics and engaging storytelling, we aim to do just that.
